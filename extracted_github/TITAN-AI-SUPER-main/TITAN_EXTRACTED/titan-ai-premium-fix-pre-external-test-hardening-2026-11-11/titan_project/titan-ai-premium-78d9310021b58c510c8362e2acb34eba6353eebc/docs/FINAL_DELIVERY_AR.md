# تقرير التسليم النهائي — TITAN AI PREMIUM (بناء تأسيسي متكامل وقابل للاختبار جزئيًا)

> **شرط التسليم:** هذه **نسخة حقيقية قابلة للتشغيل والاختبار** كأساس متكامل، لكنها **ليست مكتملة إنتاجيًا بنسبة 100%** لكل الوظائف الحية المذكورة في المواصفات (Binance/Telegram حي، استضافة 24/7، APK مختبر، تغطية حية كاملة لكل المحركات/الأقسام). ما اكتمل اختُبر فعليًا حيث أمكن؛ ما تبقى موثق بوضوح.

## 1) ما اكتمل واختُبر فعليًا
- **فحص شامل:** `python -m compileall backend/app` نظيف؛ فحص تسرب أسرار أولي (بدون قيم) لم يجد مؤشرات واضحة؛ سلامة ZIP مُتحققة.
- **اختبارات Backend (منفذة فعليًا):** `cd backend && python3 -m pytest -q` → **`26 passed, 1 skipped`**.
  - HTTP فعلي عبر `uvicorn/Starlette` + `httpx`: صحة API، الحالة، المحركات (يشمل `TITAN COMPLIANCE & POLICY ENGINE`)، تحليل قرار، MASTER `start/stop`, فحص امتثال، معرفة، دردشة grounded.
  - المصادقة: تجزئة PBKDF2+salt، allowlist، جلسات login/logout/me.
  - الحوكمة: سجل تغييرات الإعدادات.
  - بوابة أوامر + امتثال: منع سحب/تحويل API، منع تحايل، حجب Live غير مفعّل/مؤكد، مراجعة عند عدم تحقق شروط حية.
  - Shadow/محاكاة: تنفيذ كامل/جزئي، إلغاء، منع تكرار `idempotency_key`, انقطاع اتصال محاكى + عدم تكرار عند إعادة المحاولة، محفظة/PnL/رسوم/تعرض.
  - محولات Binance/Telegram برمجيًا (Mock/Shadow): لا إرسال للمنصة، لا تنفيذ حي تأسيسي، أوامر حساسة لا تُنفذ.
- **سلامة وأمان:** فصل Demo/Live وSpot/Futures/Earn، لا انتقال تلقائي Demo→Live، لا صلاحيات سحب/تحويل، الامتثال يسبق التنفيذ، الأسرار غير مخزنة في الكود/ZIP (استخدم `.env` محليًا ومراجع `env:`).
- **Backend قابل للتشغيل:** `uvicorn app.main:app` (Starlette runtime متوافق مع بيئة Python الحالية).
- **Frontend مصدر محدّث:** RTL عربي، تسجيل دخول/خروج، ربط جلسات Bearer، MASTER CONTROL UI، أقسام/حالات صادقة.

## 3) طريقة التثبيت والتشغيل (هاتف/حاسوب)
1. فك ضغط `TITAN_AI_PREMIUM_COMPLETE.zip`.
2. Backend:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate   # Windows: .venv\Scripts\activate
   pip install -r backend/requirements.txt
   cp .env.example .env
   cd backend
   python3 -m app.scripts.set_initial_password --email abdoavm02@gmail.com
   python3 -m uvicorn app.main:app --host 0.0.0.0 --port 8000
   ```
3. Frontend (بيئة Node قياسية موصى بها):
   ```bash
   cd frontend
   npm install
   npm run dev      # تطوير
   npm run build    # بناء للنشر/PWA
   ```
4. الهاتف: افتح واجهة النشر/PWA عبر المتصفح. التشغيل المستمر يتطلب خادمًا دائمًا (وليس إبقاء محرر/تطبيق الهاتف مفتوحًا).

## 4) المتطلبات الخارجية التي تحتاج توفيرها
- مفاتيح Binance **Demo/Testnet** أولًا (قراءة/تداول حسب الحاجة فقط، **بدون سحب/تحويل**) + تحقق شروط Binance/أهلية/KYC/قيود جغرافية.
- Telegram Bot Token + `chat_id/user_id` مصرح.
- مفاتيح مزودي AI (اختياري) + تحقق إقليمي/تسعير/شروط.
- استضافة VPS/Cloud + HTTPS + نسخ احتياطي + مراقبة.
- بيئة Node قياسية لبناء frontend، وأدوات Android لبناء APK إن رغبت.

## 5) ربط Binance Demo وTelegram بأمان
- ضع الأسرار في `.env` محلي/مدير أسرار الاستضافة؛ **لا تضعها في الكود أو ZIP أو GitHub**.
- Binance: فعّل صلاحيات ضرورية فقط؛ **ارفض/لا تفعّل Withdraw/Transfer**. ابدأ Demo/Testnet. راجع `https://www.binance.com/en/terms`, `https://www.binance.com/en/terms-api`, `https://developers.binance.com/`.
- Telegram: قيّد البوت على Chat/User IDs المصرح بها؛ عالج الأوامر الحساسة بتأكيد وسياسات أمان.
- فعّل `TITAN_AUTH_REQUIRED=true` وallowlist في بيئة غير محلية.

## 6) تشغيل البوت وإيقافه
- من لوحة التحكم: **START** يبدأ العمل ضمن الحالة/البيئة المختارة بعد فحوصات؛ **STOP** يوقف الإجراءات الجديدة (ولا يغلق المراكز تلقائيًا إلا بخيار تنفيذي صريح مُتحقق)؛ **EMERGENCY STOP** إيقاف طارئ مستقل للأفعال الجديدة.
- Live محجوب دون تمكين إعدادات الخادم + تأكيد صريح + تحقق امتثال/مزامنة/أهلية. لا انتقال تلقائي Demo→Live.

## 7) النسخ الاحتياطي والاستعادة
- قاعدة البيانات الافتراضية: SQLite (مسار `TITAN_DATABASE_URL`). النسخ الاحتياطي: انسخ ملف DB + `.env` الآمن/قالب الإعدادات غير السرية خارج الخدمة أثناء توقف كتابة آمن أو باستخدام آلية لقطة متسقة.
- الاستعادة: أوقف الخدمة، استعد ملف DB في مسار مُتحقق، تحقق الصلاحيات/الإعدادات، شغّل الخدمة، وافحص `/api/health` و`/api/system/status`. لا تستأنف التنفيذ الحي قبل مطابقة الأرصدة/الأوامر/المراكز مع Binance.
- احتفظ بمجلد `recovered/` والملفات الأصلية كما هي.
